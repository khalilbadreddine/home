# The 14 Kilometres That Move the World

> Demo script for the Visual Director engine. Figures are rounded and should be
> fact-checked before using this topic for a real upload.

## Hook
Fourteen kilometres. That's all that separates Europe from Africa. And every year, around a hundred thousand ships squeeze through it.

## Context
For most of history, this strait was a door you sailed past. Then, in 2007, Morocco decided to build a door you sail into.

## Build
Tanger Med. A port placed exactly where the world's shipping lanes already run. Ships between Asia and Europe don't have to detour. They just stop.

## Payoff
Today it moves more than eight million containers a year, more than any other port in Africa.

## Close
The lesson is simple. Geography is destiny, but only if you build on it.
